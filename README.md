# kpi_dev — FastAPI

Перенос всех шести HTML-макетов из Figma: главная, четыре услуги и FitFuel.
Исходные файлы в корне сохранены без изменений. Размеры desktop-макетов — 1440 px.

Проверено 08.10.2026: Docker Compose, Python 3.14.8, Chromium — **70 тестов прошли**,
покрытие строк и ветвей Python-приложения **100%**. Визуальные сравнения всех шести
страниц прошли; отчёты повторно создаются командой тестирования ниже.

## Запуск в Docker Compose

```sh
docker compose up --build -d --wait web
```

Сайт: http://localhost:8000. Проверка готовности: http://localhost:8000/healthz.
Порт можно изменить переменной `PORT`, например `PORT=8080` в локальном `.env`.
Контейнер работает от непривилегированного пользователя. Заявки сохраняются
в SQLite в постоянном томе `inquiries`, переживают перезапуск и пересборку.

```sh
docker compose logs web
docker compose down
```

`down` сохраняет заявки; `down -v` удаляет том и данные, поэтому не используйте его
для обычной остановки. Email/Telegram-уведомления не подключены: в выгрузке нет
адреса получателя или настроек доставки. Успех формы означает сохранение в базе.

## Все проверки в контейнерах

```sh
docker compose --profile test run --build --rm test
docker compose --profile test stop test-web
```

Compose сначала запускает `test-web`, ждёт успешного healthcheck, затем выполняет
pytest и Playwright/Chromium. У `test-web` отдельная временная база в tmpfs,
не связанная с заявками рабочего `web`. После остановки тестового сервиса она исчезает.

Проверяются:

- Все маршруты, ссылки, якоря, семантические заголовки, статические ресурсы и шрифт.
- Сохранение, валидация, согласие, конкурентные записи, перезапуск и отказ SQLite.
- Отсутствие публичного доступа к заявкам и внутренним файлам.
- Воспроизводимость шаблонов и сохранность всех стилей исходных слоёв.
- Скриншоты всех шести страниц на 1440 px против **исходной выгрузки**, отрисованной
  отдельно, с тем же шрифтом и `box-sizing: border-box`.
- Фильтры с пересекающимися категориями, навигация, отправка, защита от двойного
  клика и повторная отправка после ошибки.
- Отображение на 390, 768 и 1280 px без горизонтального переполнения.

`artifacts/` содержит JUnit XML, XML-отчёт покрытия, скриншоты, эталонные рендеры, изображения различий
и JSON с долей отличающихся пикселей. Порог визуального теста: менее 0,01% пикселей
с отклонением цвета более 8/255. Только три нативных поля и чекбокс исключены из
пиксельного сравнения; их работа проверяется отдельно. Порог покрытия Python — 95%.

Точность 1:1 проверяется относительно предоставленной HTML-выгрузки, а не недоступного
оригинала `.fig` или скриншотов Figma.

## Разработка

Python 3.12+; контейнер использует Python 3.14. Frontend — серверные Jinja2-шаблоны,
CSS и небольшой JavaScript без Node/npm и отдельного frontend-сборщика.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements-dev.txt -c requirements-dev.lock
python -m playwright install chromium
python -m uvicorn app.main:app --reload
```

В другом терминале с активированной `.venv`:

```sh
python -m pytest --cov=app --cov-branch --cov-report=term-missing
```

Для браузерных тестов сервер должен работать; `BASE_URL` по умолчанию
`http://127.0.0.1:8000`. Только серверные проверки: `python -m pytest -m "not browser"`.
Локальная база по умолчанию — `data/inquiries.sqlite3`; переопределение: `DATABASE_PATH`.

`scripts/build_pages.py` воспроизводимо добавляет семантические теги, ссылки,
поля формы и адаптивные классы к исходным слоям. После изменения выгрузки:

```sh
python -m scripts.build_pages
```

Генерируемые файлы находятся в `app/templates/pages/`. Не редактируйте их вручную:
меняйте генератор или исходную выгрузку. Сервер не парсит Figma при каждом запросе.
Manrope и лицензия SIL OFL размещены в `app/static/fonts/`, внешних ресурсов
во время просмотра страниц нет.
